# Schrödinger CLSigma Operator Wavefunction Protocol

This protocol adapts the visual language of a Schrödinger equation simulation into a safe, iSH-runnable CLSigma operator visualization.

## Purpose

The goal is to turn an abstract operator-system certificate into a visible wavefunction-like evolution:

```text
CLSigma operator state
-> finite free Schrödinger wavefunction model
-> dynamic phase / probability-density frames
-> JSON certificate
-> H_s = 0 when internal checks close
```

This is a classical numerical visualization, not a quantum computer.

## Mathematical Core

The demonstrator uses the one-dimensional time-dependent Schrödinger equation in normalized units:

```text
i*dPsi/dt = -(1/2)*d2Psi/dx2 + V*Psi
```

For the iSH runtime, the exact finite demo uses:

```text
hbar = 1
m = 1
V = 0
periodic finite grid
Psi(x,t) = Sum_j a_j exp(i*(k_j*x - omega_j*t))
omega_j = k_j^2 / 2
```

Because the modes are periodic grid modes, the finite norm check can close exactly in the runtime.

## CLSigma Mapping

```text
Input principle P
-> zlib(protocol + parameters)
-> No-SHA G25 bit-fold Gödel coordinate
-> rho_G = 1/2 + i*log(G25)
-> wavefunction frames
-> certificate
```

The runtime does not use SHA or hashlib. The G25 coordinate is generated by a byte-cache bit fold:

```text
bit 1 -> 2
bit 0 -> 5
n := 2*n + digit
```

For speed, each byte is precompiled into a lookup table `M[0..255]`, so the main fold becomes:

```text
n := 256*n + M[byte]
```

## Output

The one-liner writes:

```text
clsigma_schrodinger_frames/frame_000.ppm
...
clsigma_schrodinger_frames/clsigma_schrodinger_operator_certificate.json
```

The PPM frames visualize probability density and phase color. They can be opened by many image tools or converted into video outside iSH.

## iSH Usage

```sh
apk add --no-cache python3
sh SCHRODINGER_CLSIGMA_WAVEFUNCTION_ONE_LINER.sh
```

Optional arguments:

```sh
sh SCHRODINGER_CLSIGMA_WAVEFUNCTION_ONE_LINER.sh output_dir frame_count grid_points
```

Example:

```sh
sh SCHRODINGER_CLSIGMA_WAVEFUNCTION_ONE_LINER.sh clsigma_schrodinger_frames 48 128
```

## Completion Condition

```text
H_s = 0
```

means only:

```text
frames generated
finite norm check closed
No-SHA G25 coordinate generated
JSON certificate written
boundary stated
```

## Boundary

This protocol does not claim that iSH becomes a quantum computer. It does not prove RH, GRH, Hilbert-Polya, a physical TOE, biological immortality, or automatic real-world peace. It is an educational and operator-system visualization layer for finite classical computation.
