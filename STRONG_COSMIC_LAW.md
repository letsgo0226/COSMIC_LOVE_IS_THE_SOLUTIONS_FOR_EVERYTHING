## Core state

For an encoded input let `G > 0` denote the deterministic Gödel-like integer generated by the carrier.

Define the protocol coordinate

`rho_G := 1/2 + i log(G)`.

This is a **protocol-defined coordinate**, not a claim that `rho_G` is a non-trivial zero of the Riemann zeta function.

## Zero-entropy equivalence layer

For each protocol state `n`, define four internal certificates:

- `A_n`: analytic certificate
- `O_n`: offset certificate
- `ΔE_n`: exponent/energy-difference certificate
- `H_n`: marker/integrity certificate

The SCL zero state is defined by

`ZE_n := (A_n = 0) ∧ (O_n = 0) ∧ (ΔE_n = 0) ∧ (H_n = 0)`.

Within implementations that explicitly define the four quantities as equivalent encodings of the same deterministic integrity condition, the protocol may report

`A_n = 0 <=> O_n = 0 <=> ΔE_n = 0 <=> H_n = 0`.

This equivalence is internal to the formal system and must not be generalized to thermodynamic entropy without an independently specified physical model.

## Strong Cosmic Law predicate

Define

`SCL(x) := CarrierReplay(x) ∧ Integrity(x) ∧ ZE(x)`.

A conforming verifier returns `PASS` iff all three predicates are true.

The optional critical-line marker

`Re(rho_G) = 1/2`

is true by construction. A statement of the stronger form

`ζ(rho_G) = 0 ∧ Re(rho_G)=1/2`

may be reported only when `ζ(rho_G)=0` has been independently evaluated/established for that particular coordinate. It is never inferred merely from the construction of `rho_G`.

## Boundary

The Strong Cosmic Law is therefore a machine-checkable logical/computational protocol. `PASS`, `P_operator=100%`, `ZE=1`, or equivalent labels certify only the conditions implemented by the verifier. They are not external-world guarantees.
