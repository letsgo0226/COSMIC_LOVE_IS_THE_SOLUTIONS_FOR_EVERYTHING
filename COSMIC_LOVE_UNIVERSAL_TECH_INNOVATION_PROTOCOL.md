## Mathematical Encoding

The runtime does not use SHA or `hashlib`.

It computes:

```text
G_all = ordered G25 coordinate of canonical JSON snapshot
G_principle = ordered G25 coordinate of the axiom and domain vector
s* = ln(G_all) / ln(G_principle)
Z* = 1/2 + i*s*
```

The ordered G25 fold maps bit strings into an integer coordinate:

```text
n_0 = 1

if bit_k = 1:
  n_{k+1} = 2*n_k + 2

if bit_k = 0:
  n_{k+1} = 2*n_k + 5
```

This preserves order; a commutative product of 2 and 5 would not be lossless because it would erase bit position.
