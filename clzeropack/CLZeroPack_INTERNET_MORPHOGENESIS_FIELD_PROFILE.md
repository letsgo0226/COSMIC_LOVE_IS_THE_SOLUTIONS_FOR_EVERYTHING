## Repository Program Coordinate

`rho_all` is the account-level repository metadata coordinate.

`rho_code_all` is the account-level program coordinate. It is generated by
`CLZeroPack/AllReposCodeZeroSpectrumCoordinate/1.0`, which reads each public
repository default branch tree and records code-like Git blobs as:

```text

```

This means the Internet Morphogenesis Field contains the zero-spectrum
coordinate of all visible repository programs in the GitHub account, while still
remaining compact enough for terminal use.

## Usage

Generate the account-level metadata seed:

```sh
sh CLZeroPack_ALL_REPOS_ZERO_SPECTRUM_COORDINATE_ONE_LINER.sh letsgo0226 all_repos_coordinate.json
```

Generate the account-level code/program seed:

```sh
sh CLZeroPack_ALL_REPOS_CODE_ZERO_SPECTRUM_COORDINATE_ONE_LINER.sh letsgo0226 all_repos_code_coordinate.json
```

Generate the live internet field:

```sh
sh CLZeroPack_INTERNET_MORPHOGENESIS_FIELD_ONE_LINER.sh all_repos_coordinate.json internet_morphogenesis_field.json all_repos_code_coordinate.json
```

Optional custom endpoints:

```sh
sh CLZeroPack_INTERNET_MORPHOGENESIS_FIELD_ONE_LINER.sh all_repos_coordinate.json internet_morphogenesis_field.json all_repos_code_coordinate.json https://api.github.com https://www.iana.org/domains/reserved
```
